# Protocol

Smart contract protocol implementation using Hardhat.

## Setup

```bash
npm install
```

## Development

```bash
# Compile contracts
npm run compile

# Run tests
npm run test

# Start local node
npm run node

# Deploy contracts
npm run deploy
```

## Environment Variables

Copy `.env.example` to `.env` and fill in the required variables:

- `PRIVATE_KEY`: Your wallet private key for deployments
- `ETHERSCAN_API_KEY`: API key for contract verification
- `ALCHEMY_API_KEY`: API key for Alchemy network access
